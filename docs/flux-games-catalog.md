# Flux Games catalog

The Games hub only lists browser games with source available and documented mobile/touch plus desktop controls.

## Included

- TuxRacer.js — 3D racing
- AntiGravity Pool — path-traced 3D physics
- Pekka Kana 2 — WebAssembly platform adventure
- Sandspiel — physics sandbox
- A Dark Room — story, survival and settlement management
- PrinceJS — cinematic platform adventure
- XQuest JS — arcade space shooter
- OpenPanzer — turn-based strategy simulation
- Nodulus — 3D touch puzzle
- Grave Hopper — puzzle platformer
- Txtaria — touch-friendly ASCII platformer
- Flux Farm Beta — existing Flux experiment

External projects remain on their official hosts. Flux provides discovery, favorites, recent history, sharing and a safe launcher; it does not copy third-party game assets into this repository.
